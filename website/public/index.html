A FEW THINGS TO KNOW.

你可能想知道。

是免费的吗？需要注册账号吗？

免费使用，无需注册账号。软件源码采用 MIT 许可证；内置 TypeLingo 词库汇编采用 CC BY 4.0，来源及许可随软件提供。使用自己的 AI API 时，相关费用按服务提供商的规则计算。

能把快捷键设成 Windows + V 吗？

Windows + V 已由系统剪贴板占用。默认使用 Ctrl + Shift + V，你可以在设置中更换组合；如果快捷键冲突，软件会提示你重新选择。

历史记录真的没有条数限制吗？

默认容量为 0，表示不按条数自动淘汰。也可以在设置中选择容量或输入自定义条数。记录仍占用电脑的磁盘空间；管理界面分批加载，重要内容可以置顶。

没有 AI API，也能翻译整句话吗？

内置词库支持中英日已有词条的精确查询，不是整句翻译模型。未配置 API 时自动使用词库；未命中或有歧义会明确提示。整句翻译、更多词汇或其他目标语言，需要配置兼容 OpenAI 的 AI API。也可以选择“仅本地词库”始终离线查词。

图片、文件和隐私内容会怎样处理？

图片记录默认关闭，手动启用后保存原图，不额外限制大小。文件和文件路径不加入新历史，也不会被移动或删除。历史是电脑本地的明文文件，程序会跳过来源应用标记为敏感的内容，但部分应用不会添加这类标记。AI 翻译只发送当前选中的文字，不发送整个历史或图片。

点选后自动粘贴，支持哪些平台？

自动粘贴面向 Windows：在原输入框按快捷键唤出，点选词条后发送粘贴并收起。该实现已完成编译检查，仍需 Windows 实机验证。目标改变、应用权限较高或系统策略限制时可能无法自动粘贴，可使用已复制的内容手动粘贴。macOS / Linux 当前只复制并收起。
